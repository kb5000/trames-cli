# Security Policy

## Reporting a Vulnerability

**Do not open a public GitHub issue for security vulnerabilities.**

Report vulnerabilities privately via:
1. **GitHub Private Vulnerability Reporting** *(preferred)*: [Report a vulnerability](https://github.com/project-trames/trames-cli/security/advisories/new)
2. **Email**: `a123edcrfv@gmail.com` with `[SECURITY]` in the subject line

Include the affected module/commit, reproduction steps, and potential impact (for example, wire-protocol framing or terminal-control issues).

## Handling of Private Reports

Private security reports are excluded from the public-channel AI processing default and are never published without coordination with the reporter.
